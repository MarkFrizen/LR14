## Цель работы

Построить ETL/ELT-конвейер для сбора, очистки, анализа и визуализации отзывов пользователей маркетплейсов (Wildberries, Ozon).
- **Go** - высокопроизводительный сбор и предобработка (парсинг, оконная агрегация).
- **Python (Polars, DuckDB)** - аналитика, трансформация, визуализация.
- **NATS / Apache Arrow** - потоковая передача данных.
- **etcd** - координация распределённого парсинга.
- **Streamlit** - интерактивный дашборд с реальным временем.
